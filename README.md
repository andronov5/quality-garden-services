# Quality Garden Services

A responsive website for the Denver/Aurora business. Plain HTML, CSS and JavaScript; no package installation or build required.

## Preview

Open `index.html` in a browser, or serve this folder with a static file server.

## Publish through GitHub

1. Create a repository named `quality-garden-services` under the intended GitHub account.
2. Add these files to its `main` branch, preserving the `assets` and `.github/workflows` folders.
3. In **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**.
4. Run **Publish website to GitHub Pages** in the Actions tab, or push another commit.

All site links and asset paths are relative, so the site supports a GitHub Pages project subdirectory or a custom domain.
